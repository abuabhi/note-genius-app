**Getting Started Actions:**

## Flashcard Creation Methods

### 1. Manual Flashcard Set Creation
**How to access:** Click "New Set" button in header or "+ Create Flashcard Set" in empty state

**Form Fields:**
- **Name*** (Required) - Clear, descriptive set name
- **Subject*** (Required) - Select from your subjects or create new one
- **Description** (Optional) - Brief overview of the set content
- **Difficulty Level** - Beginner, Intermediate, Advanced
- **Tags** (Optional) - Add categorization labels
- **Public/Private** - Choose visibility settings

**Features:**
- Real-time validation
- Auto-save functionality
- Duplicate detection
- Subject auto-creation
- Bulk card addition

### 2. Individual Flashcard Creation
**Card Components:**
- **Front Side*** (Required) - Question, term, or prompt
- **Back Side*** (Required) - Answer, definition, or explanation
- **Hints** (Optional) - Additional clues or context
- **Images** (Optional) - Visual aids for both sides
- **Audio** (Optional) - Pronunciation or audio cues
- **Tags** (Optional) - Card-specific categorization

**Creation Methods:**
- **Quick Add** - Rapid card creation with minimal fields
- **Detailed Add** - Full-featured card creation
- **Bulk Import** - CSV/text file import
- **AI Generation** - Generate cards from topics or content

### 3. Import Dialog - Multiple Options

**File Import Tab:**
- **Supported formats:** CSV, TXT, JSON, Anki decks
- **Drag-and-drop** or browse to select
- **Auto-mapping** of front/back content
- **Batch processing** for large sets
- **Preview before import** functionality

**CSV Format Expected:**
```
Front,Back,Hint,Tags
"What is photosynthesis?","Process by which plants convert light into energy","Think about plant food","biology,science"
```

**AI Generation Tab:**
- **Topic Input** - Enter subject or topic
- **Content Source** - Paste text to generate cards from
- **Difficulty Selection** - Choose appropriate level
- **Card Count** - Specify number of cards desired
- **Quality Control** - Review and edit before adding

**Library Import Tab:**
- **Browse Categories** - Explore by subject areas
- **Search Built-ins** - Find specific topics
- **Preview Sets** - Review before copying
- **Customize Copies** - Edit after importing
- **Bulk Selection** - Import multiple sets

**Anki Import Tab:**
- **Anki Deck Upload** - Import .apkg files
- **Field Mapping** - Match Anki fields to our format
- **Media Handling** - Import images and audio
- **Preserve Scheduling** - Maintain study progress

## Study Modes & Features

### 1. Classic Study Mode
**Features:**
- **Card Navigation** - Previous/Next buttons
- **Reveal Answer** - Click to show back side
- **Difficulty Rating** - Rate how well you knew the answer
- **Progress Tracking** - Visual completion indicator
- **Session Statistics** - Real-time performance metrics

**Difficulty Ratings:**
- **Again (1)** - Didn't know, need to see soon
- **Hard (2)** - Knew with difficulty
- **Good (3)** - Knew with some effort
- **Easy (4)** - Knew instantly

### 2. Spaced Repetition System
**Algorithm Features:**
- **Adaptive Scheduling** - Cards appear based on performance
- **Forgetting Curves** - Scientific spacing intervals
- **Mastery Levels** - Progress from 1-5 difficulty levels
- **Review Timing** - Optimal review scheduling
- **Long-term Retention** - Focus on difficult cards

**Mastery Progression:**
- **Level 1:** New cards (daily review)
- **Level 2:** Learning (2-3 day intervals)
- **Level 3:** Familiar (1 week intervals)
- **Level 4:** Known (2 week intervals)
- **Level 5:** Mastered (1+ month intervals)

### 3. Test Mode
**Test Configuration:**
- **Question Count** - Choose number of questions
- **Time Limit** - Set duration (optional)
- **Question Types** - Multiple choice or typed answers
- **Random Order** - Shuffle questions
- **Immediate Feedback** - Show results after each question

**Test Features:**
- **Progress Tracking** - Visual completion bar
- **Time Remaining** - Countdown timer
- **Score Calculation** - Real-time scoring
- **Detailed Results** - Performance breakdown
- **Retake Options** - Improve your score

### 4. Quick Review Mode
**Features:**
- **Rapid Fire** - Fast-paced card review
- **Keyboard Shortcuts** - Space bar to flip, number keys to rate
- **Focus Mode** - Distraction-free interface
- **Time Tracking** - Monitor study duration
- **Streak Counter** - Track consecutive correct answers

## Tips for Effective Learning

### 1. Best Practices
**Card Creation:**
- Keep questions specific and focused
- Use clear, concise language
- Include visual aids when helpful
- Add context or hints for difficult concepts
- Test your cards before extensive study

**Study Habits:**
- **Regular Sessions** - Study consistently rather than cramming
- **Honest Ratings** - Rate difficulty accurately for optimal spacing
- **Mixed Subjects** - Interleave different topics
- **Active Recall** - Try to answer before revealing
- **Spaced Reviews** - Follow the algorithm's suggestions

### 2. Optimization Strategies
**Performance Improvement:**
- **Identify Weak Areas** - Focus on low-mastery cards
- **Adjust Difficulty** - Edit cards that are too easy/hard
- **Use Multiple Modes** - Combine study and test modes
- **Track Progress** - Monitor analytics regularly
- **Set Goals** - Establish mastery targets

**Time Management:**
- **Set Time Limits** - Use focused study sessions
- **Prioritize Reviews** - Study due cards first
- **Batch Creation** - Add multiple cards efficiently
- **Schedule Study** - Plan regular review sessions
- **Use Mobile Time** - Study during short breaks

## Troubleshooting

### Common Issues
**Import Problems:**
- Check file format compatibility
- Verify CSV column headers
- Ensure proper encoding (UTF-8)
- Review character limits
- Contact support for complex imports

**Sync Issues:**
- Check internet connection
- Refresh the page
- Clear browser cache
- Log out and back in
- Report persistent issues

**Performance Issues:**
- Reduce large image sizes
- Limit cards per session
- Close other browser tabs
- Update your browser
- Check system requirements
